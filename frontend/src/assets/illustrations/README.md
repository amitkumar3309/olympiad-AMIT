# Illustrations

Drop the launch artwork here, named exactly as `src/components/Illustration.tsx`'s
`ILLUSTRATIONS` registry — for example `hero-student.webp` and `hero-student@2x.webp`
(and optionally `.avif` versions), or a single `trophy.svg`. Rebuild, and every page
that shows that name uses the file instead of its placeholder. No code change.

The full list, with sizes and where each one appears, is in
`docs/launch/ASSETS_NEEDED.md`. Licensed or commissioned art only — never hotlinked,
never the AI mockup art (its lettering is garbled).
