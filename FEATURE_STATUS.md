# FEATURE_STATUS.md

Status values: `NOT_STARTED`, `IN_PROGRESS`, `IMPLEMENTED` (works end-to-end, verified by reading the actual data path — not just "a page exists"), `TESTED` (has automated test coverage), `DEPLOYED` (live in production).

A UI page existing with hardcoded/mock data is recorded as its own row/note — it does **not** count as `IMPLEMENTED` for the underlying feature.

**Infrastructure rows** (below the feature table) track the Milestone 1 backend foundation separately, since those are cross-cutting capabilities rather than user-facing features.

_Last updated: 2026-08-13, after **Milestone 10 (Leaderboards and Hall of Fame)** — one ranking service every standing in the product goes through, boards scoped by class and by period, deterministic tie-breaking with equal XP sharing a rank, pagination whose ranks survive a page boundary, a depth cap that keeps the public board from being walked, and a Hall of Fame built from genuine achievement rather than a second copy of the XP ranking. Before that, **Milestone 9 (Gamification Engine)** — one reward engine that every XP grant goes through, badges as tiered families distinct from achievements, a journey map, and an administrator-tunable award table that cannot re-price history. Before that, Milestone 8 (Daily Challenge) — one question a day per class, pinned to a document so it cannot change under a student, answered once, marked and explained immediately, and rewarded once per IST day through the existing XP service. Staff can schedule days in advance; an unscheduled day fills itself. Before that, Milestone 7 (Mock Test System) — staff-authored timed papers, sat under a clock the server owns: a question picker priced per test, publish/unpublish, an availability window, two independent disclosure settings, a countdown that is a display rather than a rule, per-answer autosave, automatic submission on expiry, and a ranked results table with per-question outcomes. Before that, Milestone 6 (Practice Zone). Students can now choose a subject, topic and difficulty, answer real published questions, navigate, submit, and receive a server-marked review with explanations and a performance summary — all persisted. Before that, Milestone 5 delivered the profile, dashboard, XP, levels, achievements, leaderboard and daily challenge. A follow-up pass then removed **all** remaining fabricated data: the result portal no longer hashes a typed ID into a score, the certificate page no longer prints an unearned award, the exam serves real published questions instead of five hardcoded ones, and the admin chart shows real counts instead of a sample accuracy trend. **No endpoint or page returns placeholder data any more.** Several show empty states instead, because the collections behind them are genuinely empty until exam submission exists. A global light/dark theme was also added, light by default._
